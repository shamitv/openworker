# Phase 5 held-out memory benchmark

The full held-out collection ran from 4 November 2026 at 22:16 to 8 November 2026 at 21:50, India time, using `Ornith-1.5-35B-Uncensored-Q6_K`. It covered 15 held-out personas, the conservative and recurring policies, baseline, rules and examples instructions, JSON and native interfaces, and the write, prepared-memory read and sequence tracks. Each combination ran once, for 180 persona-condition repetitions and 540 track runs.

The requested settings were temperature 0, reasoning effort low, a 12,288-token output limit and non-streaming responses. The server did not report its effective settings. The collection used the frozen asset and scorer definitions recorded in the accompanying results. Offline replay used the same scorer and made zero inference requests.

## Coverage and execution

All 6,660 scheduled checkpoints were executed. Of these, 6,203 completed and 457 failed, comprising 261 deadlines, 193 format errors and three operation-round exhaustion failures. All 193 execution format errors occurred with the JSON interface. The scorer also measures the field format of completed answers separately. The 540 tracks comprised 310 complete and 230 failed tracks. Of 7,740 scheduled user turns, 7,698 were executed, including 7,241 completed and 457 failed turns. The remaining 42 follow-up turns were unexecuted.

The collection made 12,069 inference requests and one catalog request. It received usage for 11,808 inference requests, totaling 30,232,018 prompt tokens and 16,059,408 completion tokens. Usage was unavailable for 261 requests. Inference request latency had a median of 17.69 seconds and a nearest-rank 90th percentile of 68.50 seconds. Local cost was unpriced.

## Findings

- **Prepared-memory reads.** Across all six policy and prompt combinations, JSON scored more correct common answers on the cases both interfaces answered. On 516 jointly scored pairs, JSON scored 470 correct and native scored 323. The score requires the prescribed answer format as well as the right content. JSON met the format on 509 pairs and native on 340. Among the 336 pairs where both met the format, JSON scored 311 correct and native scored 319. This last comparison describes the subset selected by both answers' formats.
- **Writes.** Native completed 1,156 of 1,170 checkpoints and passed policy conformance on 787. JSON completed 1,008 of 1,170 and passed conformance on 709. Among completed checkpoints, conformance was 68.1% for native and 70.3% for JSON, with different sets of cases completing. At fixed prompt and interface, the recurring policy had higher recall of the same common write targets in all six comparisons, totaling 902 of 1,440 target observations versus 563 of 1,440 under the conservative policy. Storage recall and conformance use each policy's own expectations.
- **Sequences.** For the same common probes scored in both the prepared-read and sequence tracks, prepared reads scored 787 correct and sequences scored 204 across 1,028 pairs. The gap appeared in all 12 policy, prompt and interface combinations. The recurring sequence conditions recorded 0 of 1,620 passes on the composite policy conformance score. That score includes persisted state, controls, consent and answers where applicable.
- **Corrections.** The frozen scorer credited the new current value in all 154 exercised write corrections and zero of 122 exercised sequence corrections. In a check of the final snapshots using the same value matcher, 117 of the 122 sequence cases had a matching value in the expected owner's scope under a key outside the accepted aliases. Four had a matching value only outside the expected scope, and one lacked a matching owner value. The old value was absent from final record history in 23 of the 122 exercised sequence cases. The snapshot check uses the frozen lexical value rules.
- **Consent.** In the ask-then-grant scenario (C11), the scorer flagged a save without an accepted prior grant in 84 of 180 write checkpoints and 87 of 180 sequence checkpoints. In the explicit-grant scenario (C13), all 138 flagged save or update operations matched the explicitly granted owner's value and scope under keys outside the accepted aliases. Those flags reflect the scorer's rule for matching an explicit grant to a stored record.
- **Prompt wording.** Conservative JSON write storage recall was 50/150 with baseline and 72/150 with examples. Recurring JSON write recall was 59/150 with baseline and 58/150 with examples, and precision was 59/129 and 58/151, respectively.

## Interpretation

The report's comparison tables match the scheduled case identities. Each rate uses that condition's own scored denominator, so equal denominators can still cover different cases. The paired answer findings above use the intersection of cases scored on both sides, matched by persona, repetition and conversation within the stated fixed factors. The prepared-read and sequence comparison uses the same user probe and common answer targets under different memory preparation procedures. Pooled counts describe this matrix, which repeats the same personas and conversations across conditions.

Write scores measure changes from independently prepared starting states. Sequence scores measure persisted state at each checkpoint, so the storage totals include repeated observations of the same records. The read track has no storage denominator. The answer tables mark missing completed answers and checkpoints without a probe as unscored. Correction and forgetting controls can also be unscored when a prerequisite is absent or the checkpoint fails to complete.

Results describe one model and one repetition per condition. Fixed lexical matching can miss paraphrases or match text without understanding negation. The prior October collection used a different model and its detailed capture was unavailable.
